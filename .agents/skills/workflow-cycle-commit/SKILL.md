# Cycle Commit

This repo-local Codex skill is generated from the installed workflow command contract.
Supporting reference material lives in `.codex-workflow/agents/` and `.codex-workflow/tasks/`.

## Command Contract

# CycleCommit

Commit a draft Cycle scope to Linear, creating the Cycle, assigning Work Items, and notifying the team.

## Purpose

Takes a draft Cycle plan generated by `workflow-cycle-plan` and commits it to Linear by creating the Cycle, assigning all scoped Work Items, setting milestones, and optionally notifying the team via Slack.

## Arguments

- `cycle`: Cycle identifier from CyclePlan (required)
- `adjustments`: Scope adjustments before committing (optional)
  - Comma-separated list of changes, e.g., `add:WI-015,remove:WI-003,reassign:WI-007:Bob`

## Execution

1. Load draft Cycle plan
   - Read from `/docs/planning/cycles/cycle-{id}.md`
   - Apply any adjustments specified

2. Invoke `mcp-sync` task with action: `createCycle`
   - Create the Cycle in Linear with dates and goal
   - Return Cycle URL and ID

3. Invoke `mcp-sync` task with action: `assignToCycle`
   - Assign all scoped Work Items to the Cycle
   - Set assignees per the plan
   - Apply priority and labels

4. Set Milestones
   - Create milestone markers in Linear
   - Associate Work Items with milestones

5. Notify team (Slack if configured)
   - Post Cycle kickoff summary to team channel
   - Include scope, milestones, and key dates

## Prerequisites

- Draft Cycle plan exists (from `workflow-cycle-plan`)
- Linear MCP configured and authenticated
- Slack MCP configured (optional, for notifications)

## Output Format

```
### Cycle Committed
- **Cycle:** Complete user profile feature
- **Linear URL:** https://linear.app/team/cycle/CYC-42
- **Duration:** Jan 20 - Feb 2 (2 weeks)
- **Items Assigned:** 12
- **Milestones Set:** 2
- **Team Notified:** Yes (Slack #team-engineering)

### Adjustments Applied
- Added: WI-015 (Auth token refresh)
- Removed: WI-003 (Deferred to next cycle)
```

`workflow-cycle-commit` cycle="2025-01-20" adjustments="add:WI-015,remove:WI-003"
